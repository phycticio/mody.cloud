## First concrete step (superseded)

The MVP spec replaced the Milestone 1.1 `hello_ai.py` task. **M0-01 (subdomain Multisite locally with wildcard TLS) is done** as of 2026-11-01; it left one open question that blocks M1, WP-Cron on subsites ([architecture.md](architecture.md#open-questions)). Next up is **M1-01**. **M2-02 is done** (2026-11-06, `tickets/M2-02-ai-agent-qwen-validator.md`): the Infomaniak provider, the brand profile table, the system prompt, the block validator and the ability `mody/generate-page` exist and are tested ([ai-engine.md](ai-engine.md)). **M3 (the agent) is done** (2026-11-06), except three items moved to other milestones: the plugin toggle tools (M4-02), the past-due check (M1-02) and limiting the agent menu to member sites (M4-01). **M3-01** built the "Mody Agent" chat in wp-admin, with page generation, `mody/open-editor`, follow-up questions, refusals and the `mody_agent_events` audit log ([ai-engine.md](ai-engine.md#the-agent)). **M3-02 is done** (2026-11-06): the six design presets and `mody/update-design`, which asks whether new colors are part of the brand ([ai-engine.md](ai-engine.md#changing-the-colors)). **M3-03 is done** (2026-11-06): `mody/publish-page` publishes a draft only when the member asks, and `mody/update-site-settings` changes the site title and tagline ([ai-engine.md](ai-engine.md#publishing-and-site-settings)). **M3-04 is done** (2026-11-06): the `ai` plugin's eight writing features (titles, excerpts and so on) get the site's brand in their system instructions ([ai-engine.md](ai-engine.md#the-ai-plugins-features)). Next is **M1-01** (registration, trial and billing), which needs the WP-Cron decision and Mollie test keys, or **M4-01** (editor redirects and gating), which can start now. The maintainer chose **M2** next (2026-11-06). **M2-01 is done** (2026-11-06): the site provisioning pipeline creates a member's site from the wizard's answers, with its profile, preset colors and a generated home page, resumable at every step ([brand-profile.md](brand-profile.md#site-creation-flow)). **M2-03 is done** (2026-11-06): the brand wizard in Network Admin → Mody → New site creates a site in three steps and follows it until it is ready ([brand-profile.md](brand-profile.md#wizard-steps)). **M2-04 is done** (2026-11-07): step 2 shows a live preview of the header and hero in the chosen colors. **M2-05 is done** (2026-11-07): an optional logo in step 2, shown in the preview and set as the new site's logo. **M2 is done locally**; in production new sites wait for the wildcard DNS and TLS (M5). **M4-01 is done** (2026-11-07): on member sites, members cannot install, upload, activate or switch plugins and themes, and pages, patterns and menus open in the Site Editor (posts keep the block editor). Next in M4: **M4-03** (the `ai` plugin on member sites) and **M4-02** (the plugin market). The maintainer also asked for the agent as a chat bubble in the editor that edits what is open: tickets **M3-05** (the bubble, done 2026-11-07), **M3-06** (editing the open page or block, done 2026-11-07) and **M3-07** (templates and parts). **M2-06 is done** (2026-11-07): the six presets are the theme's style variations, shown in the Site Editor's Styles and editable per site. **M2-07** (a free-font repository) is planned.

Sections 5, 6, 7 and 9 of the briefing (tiers, brand profile, coherent generation, Newsletter) define the target data architecture for Phases 2 and 3. Details are in [ai-engine.md](ai-engine.md) and the documents linked from the table above.
