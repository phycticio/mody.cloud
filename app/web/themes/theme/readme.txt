The block theme of Mody Cloud: templates, parts, a five-color palette and Inter, all edited in the Site Editor.

== Description ==

The theme every Mody Cloud site starts from, with its default values:

* a Full Site Editing theme: templates and parts are blocks, styles live in theme.json;
* a palette of five named colors (primary, secondary, accent, base and contrast) and style variations;
* Inter, served from the theme's own folder, with no Google Fonts.

Mody Patterns' collection is written for this palette. It needs no plugin. It calls nothing outside your site.

== Installation ==

1. Download the zip from mody.cloud.
2. In wp-admin, Appearance → Themes → Add New → Upload Theme, choose the zip, then Activate. Or with WP-CLI: `wp theme install mody-theme-0.1.0.zip --activate`.
