# Mody Cloud

Sovereign WordPress sites, generated by AI from a brand profile. Mody Cloud is a non-profit association for digital sovereignty: members define their identity once and an AI agent builds every page of their site faithful to it. The whole stack is European or Swiss, fees cover real costs, and members own their code and data. More in [documentation/project-overview.md](documentation/project-overview.md).

**Status:** early. Milestone 0.1 is in progress. This repository is a clean base (Docker stack and a Full Site Editing theme scaffold). The AI agent, brand profile and memberships are not built yet. See [documentation/roadmap.md](documentation/roadmap.md).

## Stack

| Layer | Technology |
| --- | --- |
| Web server | Nginx (alpine) |
| Application | WordPress on PHP-FPM (alpine), version set by `WORDPRESS_VERSION` |
| Database | MariaDB 11.4 |
| Cache | Redis (alpine) |
| Mail (local) | Mailpit |
| Dependencies | Composer. Plugins and themes install into `app/web/`. |
| Theme | Block theme (FSE) in `app/web/themes/theme`, styled through `theme.json` |
| Dev tooling | Query Monitor (the only dev requirement) |

Core and content are split Bedrock-style: WordPress core in `app/wp`, content in `app/web`. Details, and what was deliberately not adopted from the briefing, in [documentation/architecture.md](documentation/architecture.md). The theme is described in [documentation/theme-development.md](documentation/theme-development.md).

## Quick start

Requirements: Docker with Compose v2, `mkcert`, and `127.0.0.1 mody.cloud.local mail.mody.cloud.local` in `/etc/hosts`.

```bash
cp sample.env .env
./bin/certs
mkdir -p app/logs && touch app/logs/debug.log && chmod 666 app/logs/debug.log
docker compose up -d --build
./bin/version 7.0 --no-backup
./bin/composer install
./bin/wp core install --url="https://mody.cloud.local" --title="Mody Cloud" \
  --admin_user=admin --admin_email=admin@mody.cloud --admin_password=password --skip-email
./bin/wp theme activate theme
```

Then open `https://mody.cloud.local`. Captured mail is at `https://mail.mody.cloud.local`. Full instructions, environment variables and known issues are in [documentation/local-development.md](documentation/local-development.md). These steps have not been run end-to-end since the repository cleanup.

## Common commands

```bash
docker compose up -d                          # start
./bin/wp <wp-cli args>                        # WP-CLI inside the container
./bin/composer <args>                         # Composer inside the container
docker exec mody_cloud_server nginx -s reload # reload Nginx
```

All commands, and which scripts are stale: [documentation/local-development.md](documentation/local-development.md#commands).

## Repository layout

```text

compose.yml           local stack

```

The full tree with explanations is in [documentation/architecture.md](documentation/architecture.md#repository-layout).
